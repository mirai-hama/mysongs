曲の登録・編集

カポ位置とチューニングは曲ごとに保存されます。「半音下げ」はギター全体を通常より半音低く合わせる設定です。

①歌詞を入力 → ②下のプレビューでコードを付けたい文字をタップ → ③コードを選ぶ。コードは選んだ文字の真上に付きます。コードを付けた文字をもう一度タップすると変更できます。

間奏を入れるときは、歌詞欄の入れたい場所に「【間奏】」だけを1行で入力してね。上下を1行ずつ空けると見やすくなります。

歌詞プレビュー

コードを選択

Fなどのセーハコードは、演奏画面で黒い棒として表示されます。

イントロ・間奏・アウトロなど

コード進行を1行ずつ入力します。イントロは曲の冒頭、アウトロは最後に表示されます。

間奏を歌詞の途中に入れたい場合は、歌詞欄の入れたい場所に「【間奏】」だけを1行で入力してください。その場所に間奏が表示されます。

例：
【イントロ】 G / C / D / F
【間奏】 G C / D / F G
【アウトロ】 C / G

演奏画面

演奏画面は縦方向にスクロールできます。印刷画面ではA4向けのレイアウトになります。
